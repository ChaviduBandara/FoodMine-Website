# Food Mine

Food Mine is a simple front-end Angular web application where users can browse a variety of meals, view prices and ratings, and add meals to a cart.

This project demonstrates the use of core Angular features such as **components**, **routing**, and **data binding**.

## Features

- **Meal Browsing**: View a collection of meals in a clean and simple interface
- **Price Display**: See meal prices clearly
- **Ratings**: View ratings for each meal
- **Add to Cart**: Add selected meals to the cart
- **Angular Routing**: Navigate between different pages/components
- **Reusable Components**: Built using Angular’s component-based structure
- **Responsive Layout**: Simple layout suitable for basic front-end use

## Project Overview

Food Mine is a beginner-friendly Angular project focused on building a food ordering interface.  
It allows users to explore meals and interact with a shopping-cart-style experience.

The main purpose of this project is to practice Angular fundamentals and understand how front-end applications are structured using components and routing.
